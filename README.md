One office joke, 156 characters, written for a judge that rewards a turn in the final words. The setup is the oldest promise in corporate life — *there are no bad questions* — and the punchline is the company answering it with a permissions change and a calendar invite rather than a word. `main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), byte-identical on every run, stdlib only.

## Run it

```sh
python3 main.py
```
